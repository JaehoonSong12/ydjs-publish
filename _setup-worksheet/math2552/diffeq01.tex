  \item \textbf{Differential Equation Classification} (10 points)\\
  It can be helpful to classify a differential equation, so that we can predict the 
  techniques that might help us to find a function which solves the equation. Two 
  classifications are the \textbf{order of the equation} -- (what is the highest 
  number of derivatives involved) and whether or not the equation is linear. \\
  \textbf{Linearity} is important because the structure of the the family of solutions to a 
  linear equation is fairly simple. Linear equations can usually be solved 
  completely and explicitly. Determine whether or not each equation is linear:
  \begin{enumerate}[label=\arabic*.]
    \item $y^{\prime \prime}-y+y^2=0$\\
    \begin{subanswer}
      2nd order Nonlinear
    \end{subanswer}
    \item $\frac{d y}{d t}+t y^2=0$\\
    \begin{subanswer}
      1st order Nonlinear
    \end{subanswer}
    \item $\left(1+y^2\right) \frac{d^2 y}{d t^2}+t \frac{d y}{d t}+y=e^t$\\
    \begin{subanswer}
      2nd order Nonlinear
    \end{subanswer}
    \item $\frac{d^4 y}{d t^4}+\frac{d^3 y}{d t^3}+\frac{d^2 y}{d t^2}+\frac{d y}{d t}=1$\\
    \begin{subanswer}
      4th order Linear
    \end{subanswer}
  \end{enumerate}
