\section{Variables and Expressions / \kr{변수와 식}}

Numbers are not always enough. Sometimes we don't know the exact value we are working with, but we still need a way to describe it. That's where variables come in. A variable is a symbol, usually a letter, that can stand for a number. With variables, we can write ideas as expressions instead of full sentences.

Think of \(3x + 5\). It doesn't just mean “a number.” It means something specific: three times a 
number, then add five. If \(x = 2\), the expression becomes \(3(2) + 5 = 11\).

Variables also let us describe real life. If you earn \$10 for every hour you work, you don't have 
to keep writing “10 times the number of hours.” You can just write \(10h\). When \(h = 5\), 
that becomes 50. This is the power of algebra: turning words into symbols we can calculate

\blockquote{A variable is a letter that represents a number.}
\kr{변수(variable)는 숫자를 대신하는 문자이다.}

\blockquote{An expression is a mix of numbers, variables, and operations.}
\kr{식(expression)은 숫자, 변수, 연산 기호의 조합이다.}

Examples:
\[
3x + 5, \quad 7y - 2, \quad 10h
\]

\subsection{What are Variables and Expressions? / \kr{변수와 식이란?}}
A \textbf{variable} is a placeholder for numbers.  
An \textbf{expression} shows a relationship using variables and numbers.

\textbf{Examples}:  
\begin{itemize}
    \item \(3x + 5\)
    \item \(7y - 2\)
    \item \(10h\)
\end{itemize}
Each expression can change depending on the value of the variable.

\section{Simplifying Expressions / \kr{식 단순화하기}}

Expressions can look messy, but we can simplify them. Simplifying means combining 
like terms and applying the distributive property.

Like terms are terms that share the same variable. \(2x + 3x\) is really \(5x\). The distributive property is another tool: \(3(x + 4)\) is the same as \(3x + 12\). These two ideas—combining and distributing—make expressions shorter and easier to handle.  


\blockquote{Simplifying makes math clearer.}
\kr{식 단순화는 수학을 더 명확하게 만든다.}

Examples:
\[
2x + 3x = 5x, \quad 4(y+2) = 4y+8
\]

\subsection{What does it mean to Simplify? / \kr{단순화란?}}
\begin{enumerate}
  \item Combine like terms. \kr{동류항을 정리한다.}
  \item Apply distribution. \kr{분배법칙을 적용한다.}
\end{enumerate}

\section{Solving One-Step Equations}
\kr{(1단계 방정식)}

\blockquote{Use inverse operations to isolate the variable. Do the same to both sides.}

\blockquote{Equations are like balances. Whatever you do to one side, you must do to the other.}

\kr{equation(방정식)은 balance(저울)과 같습니다. 한쪽에 한 연산을 하면, 반대쪽도 똑같이 해야 균형이 유지됨}

\subsection{What You'll Learn}
\begin{itemize}
    \item Solve equations in one step
    \item Understand inverse operations
\end{itemize}

\subsection{Key Ideas}
\begin{itemize}
    \item Use \textbf{inverse operations} to isolate the variable.
    \item Do the same thing to both sides of the equation.
\end{itemize}

\blockquote{A one-step equation is solved with just one move—addition, 
subtraction, multiplication, or division.}

\kr{one-step equation(1단계 방정식)은 한 번의 연산으로 해결되는 식 예시: x + 7 = 12 → x = 5}


\textbf{Examples:}
\[
x + 4 = 9 \Rightarrow x = 5
\]
\[
5x = 20 \Rightarrow x = 4
\]

\subsection{Real-World Example}
If \$20 is 5 times the cost of one notebook:
\[
5x = 20 \Rightarrow x = 4
\]

\subsection{Did You Know?}
Solving equations is like solving a riddle or puzzle.

\subsection{Tips for Students}
\begin{itemize}
    \item Ask: “What's happening to the variable?” Then do the opposite.
    \item Keep both sides equal.
    \item Plug your answer back in to check.
\end{itemize}

\section{Solving Multi-Step Equations}
\kr{(여러 단계 방정식)}

\blockquote{First, simplify both sides. Then, isolate the variable step by step.}

\blockquote{Not all equations are simple. Some take more than one step.}

\kr{모든 방정식이 쉽지는 않음. 어떤 것은 여러 단계를 거쳐야만 풀수 있음}

\subsection{What You'll Learn}
\begin{itemize}
    \item Solve equations with more than one operation
    \item Use combining like terms and distribution
\end{itemize}

\subsection{Key Ideas}
\begin{itemize}
    \item First, simplify both sides.
    \item Then, isolate the variable step by step.
\end{itemize}

\blockquote{A multi-step equation needs distribution, combining like terms, or more than one operation.}

\kr{multi-step equation(여러 단계 방정식)은 분배법칙, 동류항 정리, 또는 여러 연산을 차례대로 사용해야 풀림 예시: -3x-4(4x-8) = 3(-8x-1) → -3x-16x+32 = -24x-3 → -19x+32 = -24x-3 → -19x+24x+32 = -24x+24x-3 → 5x+32 = -3 → 5x+32-32 = -3-32 → 5x = -35 → 5x/5 = -35/5 → x = -7}


\textbf{Example:}
\begin{align*}
2(x + 3) &= 14 \\
2x + 6 &= 14 \\
2x &= 8 \\
x &= 4
\end{align*}

\subsection{How This Helps}
Solving multi-step equations builds confidence and logical thinking.

\subsection{Did You Know?}
Multi-step equations are used in budgeting, engineering, and cooking.

\subsection{Tips for Students}
\begin{itemize}
    \item Don't rush—write each step clearly.
    \item Simplify both sides before solving.
    \item Check your solution.
\end{itemize}

\section{Inequalities}
\kr{(부등식)}

\blockquote{If you multiply or divide by a negative number, flip the inequality sign.}

\blockquote{Inequalities tell us ranges. Instead of saying x = 5, we might say x > 5.}

\kr{inequality(부등식)은 값의 범위를 나타냄 예시: x = 5 대신 x > 5라고 하면, x는 5보다 큰 모든 값을 가질 수 있음}

\subsection{What You'll Learn}
\begin{itemize}
    \item Solve basic inequalities
    \item Graph answers on a number line
\end{itemize}

\subsection{Key Ideas}
\begin{itemize}
    \item Inequality signs:
    \begin{itemize}
        \item $>$ greater than
        \item $<$ less than
        \item $\geq$ greater than or equal to
        \item $\leq$ less than or equal to
    \end{itemize}
    \item If you multiply or divide by a negative number, \textbf{flip the inequality sign}.
\end{itemize}

\blockquote{If you multiply or divide by a negative number, you flip the sign.}

\kr{부등식에서 음수로 곱하거나 나눌 때는 부등호 방향을 바꿔야 함 예: −2x < 6 → x > −3}


\textbf{Examples:}
\[
x - 3 > 2 \Rightarrow x > 5
\]
\[
-2x < 6 \Rightarrow x > -3
\]

\subsection{Everyday Example}
A sign says: “You must be under 18 to enter.” That means:
\[
x < 18
\]

\subsection{Did You Know?}
Inequalities are used in business, programming, and transportation.

\subsection{Tips for Students}
\begin{itemize}
    \item Treat inequalities like equations—unless multiplying/dividing by a negative.
    \item Graph solutions:
    \begin{itemize}
        \item Open circles ($\circ$) for $<$ or $>$
        \item Closed circles ($\bullet$) for $\leq$ or $\geq$
    \end{itemize}
    \item Test a number to check your solution.
\end{itemize}
