\chapter{Variables and Algebra}
\kr{(문자와 대수)}

Welcome to the world of algebra! In this chapter, we'll learn how to use 
letters like \textbf{x} and \textbf{y} to represent numbers. These letters 
are called \textbf{variables}, and they help us write expressions and 
solve equations. Algebra might seem like a new language, but once you 
understand the rules, it can actually make math easier. Let's explore 
how we can describe patterns, solve problems, and think logically 
using simple algebraic tools.

Variables are like mystery boxes that can hold different numbers. When 
we write expressions like \(3x + 5\), we're creating a rule that works 
for any value of \(x\). This powerful idea helps us solve problems 
where we don't know the answer yet, but we know how things relate to 
each other.
