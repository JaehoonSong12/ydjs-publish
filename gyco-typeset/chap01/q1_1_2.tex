\subsection{Long Question (Answer)}
Write the number $5{,}041$ in expanded form. Then explain what each digit means based on its place.

\textbf{Answer:}\\
\textbf{Expanded form:} $5000 + 0 + 40 + 1$\\
\textbf{Explanation:}
\begin{itemize}
  \item $5 = 5000$ (thousands place)
  \item $0 = 0$ (hundreds place)
  \item $4 = 40$ (tens place)
  \item $1 = 1$ (ones place)
\end{itemize}
