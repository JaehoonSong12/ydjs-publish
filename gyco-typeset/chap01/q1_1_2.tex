\subsection{Challenge: Comparing Numbers (Answer)}
Two numbers have the same digits but in a different order: 5,104 and 4,105. 
Which number is greater, and how do you know? Explain using place value.\\

\textbf{Answer:}\\
\textbf{5,104 is greater} because the \textbf{5} is in the \textbf{thousands place}, meaning 5000.\\
In 4,105, the \textbf{4} is in the thousands place, meaning 4000.\\
So: \textbf{5,104 > 4,105}
