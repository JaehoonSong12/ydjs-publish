\section{Curriculum and weekly binders}
The \emph{Summer 2025 DSAT Math Curriculum} lives in the shared folder. Students receive a weekly binder that matches the curriculum exactly. If pacing changes (slower or faster), coordinators are notified so binder distribution can be delayed or moved up as needed.

\section{Supplemental resources}
Extra PDFs are in the shared \emph{DSAT Math} folder. Use them when helpful to reinforce or clarify lessons.

\section{Later-week pacing}
Later weeks intentionally list fewer topics, since earlier weeks may run long. If the class finishes early, pull in extra drills that were not used in Weeks~2--3 for additional practice.

\section{Test materials (Siyi Wang tests)}
Review every Siyi Wang test carefully; many contain errors. When a Siyi Wang test is paired with an alternate, prefer the alternate if the Siyi Wang version has too many mistakes.

\section{Google Classroom}
Ensure all students join Google Classroom after Day~1. Use it for homework reminders, announcements, and urgent updates.

\section{Curriculum notes}
Instructor notes appear as cell comments in the digital curriculum (hover to read). Read all embedded comments before teaching each lesson.

\section{Professional expectations}
Arrive at least 15~minutes before class starts. Dress professionally, including closed-toe shoes and appropriate attire. Stay patient and keep lessons engaging.

\section{Student engagement}
Maintain a supportive environment so students leave feeling more confident about the SAT.
