  \item \textbf{Solving for $2n$} (10 points)\\
  If $6n + 40 = 3(2n - 20) + 2n$, what is the value of $2n$?
  \begin{subanswer}
    Let's solve step by step:
    
    $6n + 40 = 3(2n - 20) + 2n$
    
    Distribute the 3: $6n + 40 = 6n - 60 + 2n$
    
    Combine like terms: $6n + 40 = 8n - 60$
    
    Subtract $6n$ from both sides: $40 = 2n - 60$
    
    Add 60 to both sides: $100 = 2n$
    
    Therefore, $2n = 100$
  \end{subanswer}



  \item \textbf{Game Store Sales} (10 points)\\
  The game store sells both board games and figurines. Board games sell for $\$40$ 
  a game and figurines sell for $\$15$ a figurine. If the store sells 80 total pieces 
  of merchandise and earned $\$2625$ from those sales, how many board games did the 
  game store sell?
  \begin{enumerate}[label=(\Alph*)]
    \item 23
    \item 40
    \item 48
    \item 57
  \end{enumerate}
  \begin{subanswer}
    Let $b$ = number of board games and $f$ = number of figurines.
    
    We have two equations:
    $b + f = 80$ (total pieces)
    $40b + 15f = 2625$ (total revenue)
    
    From the first equation: $f = 80 - b$
    
    Substitute into the second equation:
    $40b + 15(80 - b) = 2625$
    $40b + 1200 - 15b = 2625$
    $25b + 1200 = 2625$
    $25b = 1425$
    $b = 57$
    
    The store sold 57 board games.
    
    Answer: D
  \end{subanswer}
